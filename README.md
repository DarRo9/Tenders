Сервис проведения тендеров

Как запустить:

1 вариант:
make run

2 вариант:
docker compose up -d

Реализован на языке Go и предназначен для управления тендерами и ставками на них через HTTP API.

Основные технологии и библиотеки:
Язык программирования: Go (версия 1.22.3)
Веб-фреймворк: Gin
Работа с базой данных: pgx (PostgreSQL драйвер)
Миграции базы данных: golang-migrate/migrate
Логирование: logrus
Docker и docker-compose для контейнеризации и запуска
Makefile для автоматизации запуска

Краткое описание функциональности:
Создание, изменение, просмотр тендеров и управление их статусами и версиями
Создание и управление ставками (bids) на тендеры, включая их статусы, версии, комментарии и обратную связь
Получение информации о тендерах и ставках, фильтрация и пагинация
Проверка состояния сервиса (эндпоинт ping)
Аутентификация и авторизация пользователей (по коду видно, что есть проверки прав и существования пользователя)
Работа с ошибками и возврат корректных HTTP-статусов

Проект поддерживает все основные операции с тендерами и ставками, а также реализует версионирование и откат изменений.
